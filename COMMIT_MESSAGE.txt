SUMMARY (Title):
Fix: Resolve black screen issue - disable SSR, fix VendorController, add missing vendor Show page

DESCRIPTION (Body):

## Problem
Application was showing a blank screen due to multiple issues:
1. SSR (Server-Side Rendering) enabled but SSR bundle missing
2. PHP syntax error in VendorController (variable name conflict)
3. Missing vendors/Show.vue component
4. Vite dev server not running (requires `npm run dev`)

## Changes Made

### Backend Fixes
- **VendorController.php**: Fixed variable naming conflict in nested closures
  - Changed `$query` to `$vendorQuery` in main query builder
  - Prevents PHP parse error when using closures with `with()` method

### Frontend Fixes
- **vite.config.ts**: Disabled SSR configuration
  - Commented out `ssr: 'resources/js/ssr.ts'` line
  - Prevents Inertia from looking for missing SSR bundle
  
- **vendors/Show.vue**: Created missing vendor detail page component
  - Displays vendor information (name, email, phone, address)
  - Shows associated purchase orders
  - Includes proper breadcrumbs and navigation

### Configuration
- Removed old build artifacts (public/build, bootstrap/ssr)
- Rebuilt frontend assets with `npm run build`
- Cleared all Laravel caches

## Files Changed
- `vite.config.ts` - Disabled SSR
- `app/Http/Controllers/Web/VendorController.php` - Fixed syntax error
- `resources/js/pages/vendors/Show.vue` - Created new component

## Testing

- ✅ Laravel boots successfully
